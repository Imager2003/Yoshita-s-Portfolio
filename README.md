# Yoshita Sharma — Portfolio

A static, responsive portfolio website for Yoshita Sharma, designed around a sophisticated ivory / charcoal / burgundy legal-professional visual identity.

## Files

- `index.html` — complete website
- `styles.css` — responsive styling, typography and animations
- `script.js` — navigation, scroll progress and reveal animations
- `assets/yoshita-sharma.png` — provided professional photograph
- `assets/Yoshita-Sharma-Resume.pdf` — provided resume, linked from the CV buttons

## Deploy to GitHub + Vercel

1. Create a new GitHub repository.
2. Upload all files and the `assets` folder while preserving the folder structure.
3. Go to Vercel and import the GitHub repository.
4. Framework preset: **Other** (or leave it as detected).
5. Build command: leave blank.
6. Output directory: leave blank / root.
7. Deploy.

This is a dependency-free static site, so no `npm install` or build step is required.

## Customisation

Edit the content directly in `index.html`. Colours, typography and layout are controlled in `styles.css`.
